# AI integration
First run a real provider spike. Candidates: Stable Fast 3D https://huggingface.co/spaces/stabilityai/stable-fast-3d and TripoSR https://huggingface.co/spaces/stabilityai/TripoSR . Public Spaces may be offline, queued, gated or quota-limited. Verify live availability, terms, license, API schema and output format before selecting. No guaranteed free hosted API. Do not hardcode guessed Gradio endpoint names; inspect with gradio_client Client.view_api() and test a real image. Use HF_TOKEN only server-side if needed.

Provider adapter: submit(image, options), get_status(job), fetch_result(job). If provider returns OBJ or another mesh format, convert and validate GLB with a tested tool; preserve textures or disclose missing textures. Prefer native GLB. Implement bounded timeout, retry transient errors, quota error and optional fallback only when configured. Never substitute sample output for failed inference. Do not send images to third parties without informing users. Avoid training from scratch. If no free endpoint works, stop and report; optional self-hosted GPU inference requires separate setup.
