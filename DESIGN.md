# UI/UX specification
Approved direction: dark premium workspace, charcoal and warm copper, restrained glass. Reference: design-reference.png. Approximate implementation tokens: background #101011, panel #19191B, raised #232326, border #343437, primary text #F5F3F0, secondary #A6A3A0, accent #F79448, accent pressed #D87532. Use dark text on bright orange where contrast requires it. Geist or Inter; 8px spacing system; 12–20px panel radii. No excessive glows, gradients, decorative cards or generic AI illustrations.

Desktop: narrow sidebar (Create 3D, My Models, Settings), dominant central viewport, right input/settings panel. Top title 2D to 3D. Viewer toolbar: orbit, pan, zoom, reset, fullscreen; textured/wireframe only if supported. Bottom: auto rotate, View in AR, Download. Right: image preview, replace, provider selector if multiple verified, background removal only if supported, Generate 3D. Do not show fictional credit quotas or quality levels from reference.

Screens: landing (optional), empty workspace, uploaded image, processing, result, error, library, QR dialog, mobile AR landing, settings. On mobile stack upload and viewport; use sticky primary action and touch-sized controls. Keyboard navigation, visible focus, reduced motion, accessible labels and contrast. Show actual progress only if provided, otherwise indeterminate stages. Keep sample models labeled.
