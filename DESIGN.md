# UI/UX specification
Approved direction: dark premium workspace, charcoal and warm copper, restrained glass. Reference: design-reference.png. Approximate implementation tokens: background #101011, panel #19191B, raised #232326, border #2C2C30 (strong #3E3E43), primary text #F5F3F0, secondary #A6A3A0, muted #787572, accent #F79448, accent pressed #D87532. Use dark text (#14110F) on bright orange where contrast requires it. Inter; 8px spacing system; restrained 10–16px radii (16px panels, 12px cards/toolbars, 10px controls). No excessive glows, gradients, decorative cards, oversized headings or generic AI illustrations.

Desktop (lg+): narrow sidebar (Create 3D, My Models, Settings + honest backend status), dominant central viewport, right input/settings panel. Tablet (md–lg): top header with inline navigation tabs and balanced two-column workspace. Mobile (< md): stacked viewport and upload panel with sticky bottom navigation and 42–46px touch targets. Top title 2D to 3D. Viewer toolbar: orbit, pan, zoom, reset, fullscreen with accessible tooltips; textured/wireframe only if supported. Bottom: auto rotate, 360° reset, View in AR, Download GLB. Right: image preview, replace, camera capture, provider selector if multiple verified, background removal only if supported, explicit external processing consent checkbox, Generate 3D. Do not show fictional credit quotas or quality levels from reference.

Reusable design system (`frontend/components/ui/`): `Button` (primary, secondary, ghost, danger, icon, loading), `TextInput`, `Checkbox`, `Select`, `CopperSwitch`, `Dialog` (native `<dialog>` with `closedby="any"` + Safari fallback), `Tooltip` (`popover="hint"` + `interestfor`), `Spinner`, `ProgressBar`, `Skeleton`, `Badge`, `AlertBanner`, and `ErrorState`.

Screens: empty workspace, uploaded image, processing (with indeterminate/determinate `<progress>` and Cancel Job), result, error, library (My Models), QR dialog, mobile AR landing, settings. Keyboard navigation, visible focus, reduced motion, accessible labels and contrast. Show actual progress only if provided, otherwise indeterminate stages. Keep sample models labeled.
