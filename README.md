# Vision3D
AI image-to-3D mini-project with interactive 360° viewing and mobile AR.

## Start here
Read AGENTS.md, REQUIREMENTS.md, ARCHITECTURE.md, DESIGN.md, AI_INTEGRATION.md, AR.md, API.md, DATA.md, TESTING.md, DEPLOYMENT.md and task.md before coding. Follow task.md in order. The included design reference is a visual target, not a working application.

## Stack
Next.js App Router, TypeScript, Tailwind CSS, FastAPI, Python, Gradio client, Google model-viewer, optional Supabase storage/database. No compulsory login or billing for MVP.

## Run locally (planned commands)
Frontend: `npm install && npm run dev` in frontend. Backend: create a Python virtual environment, install requirements.txt and run `uvicorn app.main:app --reload` in backend. These commands become usable after scaffolding. Copy example environment files and configure provider/storage. Never commit secrets.
