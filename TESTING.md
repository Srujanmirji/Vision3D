# Testing
Unit: image decoding and limits, adapter errors, status transitions, token expiry, GLB validation. Integration: real provider smoke test with a chair and a shoe; test quota, timeout, malformed output and fallback. Mock provider only in automated tests. E2E: upload → job → real GLB → rotate → download → QR → mobile page. Verify downloads open in an independent 3D viewer. Test mobile capture permission denied, unsupported AR, expired link, slow network, retry and deletion. Test keyboard and responsive layouts. Device acceptance: iPhone Safari Quick Look and compatible Android Chrome Scene Viewer/WebXR. Record actual devices, results and unresolved failures. Do not claim tests run unless executed.
